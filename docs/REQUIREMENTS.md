## Scope decisions and limits

One unit and one tenant per fixed monthly lease; no proration, rent escalation, multi-currency or accounting general ledger. Floors are labels. No claim of legal compliance, completed municipal registration or live provider verification. Listing photos are protected vault attachments. Production load testing, full accessibility review, scanner validation and backup restoration remain deployment acceptance work.

## ClickUp import

Import `clickup-backlog.csv` as tasks. Map Task Name, Description and Status. Parent Task, Requirement ID and Dependencies can be mapped as text/custom fields and used to arrange subtasks and links after import; no claim is made that an importer automatically resolves symbolic dependencies. Completed = implemented code; Review = limited/manual acceptance; Blocked = missing external dependency.
